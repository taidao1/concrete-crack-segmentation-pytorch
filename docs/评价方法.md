# 评价方法

本页定义最终版本的数据划分、整图推理、像素指标与图片级辅助判断。最终成绩见[测试报告](../reports/evaluation/unet_resnet34_final_test.md)，实验过程见[实验记录](实验记录.md)。

## 数据划分与选模

458张原图按seed=1随机划分为训练322、验证68、测试68，清单分别为 [train_ids.txt](../data/train_ids.txt)、[val_ids.txt](../data/val_ids.txt) 和 [test_ids.txt](../data/test_ids.txt)。三份清单编号无交集，裁剪块不跨原图所属集合。

该划分未核验近重复、建筑或拍摄场景关联，场景独立性尚未确认。数据来源、许可及审计范围见[数据说明](数据说明.md)。

每轮整图验证累计像素计数，以验证IoU改善时的检查点选模。最终测试前冻结epoch20权重和以下规则，测试结果不用于继续选择权重、阈值或后处理。

| 冻结项 | 设置 |
| --- | --- |
| 模型 | SMP U-Net，ResNet34编码器，RGB输入，单通道logits |
| 检查点 | `outputs/run_20261024_181934_060182/crack_segmentation_model.pth`，epoch20 |
| 权重SHA-256 | `0dbddc203bee5511a2e7b67438c09ca7b01b42305e986b8214ab36bdc6e6e692` |
| 模式与设备 | `model.eval()`，无梯度推理，CUDA |
| 测试范围 | `data/test_ids.txt` 中全部68张完整原图 |

## 输入与整图推理

1. 原图、标注分别按自身EXIF规范化方向。原图转RGB和float32、除以255，再按ImageNet mean `[0.485, 0.456, 0.406]`、std `[0.229, 0.224, 0.225]` 标准化。
2. 标注转灰度，灰度值≥128为裂缝、其余为背景。
3. 原图不缩小、不随机裁剪。使用512×512窗口、常规步长512，末窗贴边以覆盖全部原图；输入高、宽须均至少512。
4. 各窗口logits经sigmoid转为概率。重叠区域累加并除以覆盖次数，平均概率≥0.5生成裂缝mask。
5. 遍历清单全部图片，在与标注对齐的原图尺寸上计数，每个像素只计一次；读取或推理异常直接报告。

## 全局像素指标

裂缝是前景。TP表示真值与预测均为裂缝的像素，FP表示背景被预测为裂缝，FN表示裂缝被预测为背景。

先逐图计数，再累计整套原图的TP、FP、FN，最后计算：

```text
IoU       = TP / (TP + FP + FN)
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1 / Dice = 2TP / (2TP + FP + FN)
```

零分母记为 `None`，不替换为任意满分。这里报告的是全局累计指标，不是逐图IoU均值，也不是训练随机裁剪区域的分数。训练BCE与阈值后的分割指标分别解释。

最终测试累计TP=8,848,419、FP=1,207,311、FN=1,525,766，对应IoU76.40%、Precision87.99%、Recall85.29%、F1 86.62%。记录见[结构化测试指标](../reports/evaluation/unet_resnet34_final_test_metrics.json)和[终端输出](../reports/evaluation/logs/unet_resnet34_final_test.txt)。测试循环进度条约76秒，包含图像读取与计算、不含模型创建和加载，不作为纯模型吞吐速度。

## 图片级辅助判断

预测mask的裂缝像素占全图比例≥0.003（0.3%）时，判断为“有裂缝”。主数据集图片级真值由真实mask是否存在前景确定。该规则只生成布尔结论，不修改分割mask，不改变像素IoU。

68张测试图全部有裂缝，68/68检出只说明这批阳性样本全部检出；没有真实阴性，无法估计无裂缝照片误报率，不能称为通用检测准确率100%。

[六张外部试用照片](../reports/evaluation/external_presence_fresh_v1/report.md)使用同一冻结模型、0.5像素阈值和0.003面积阈值。图片级标签在推理前暂定，未经专家核验，得到TP=2、FP=3、FN=1、TN=0。它们是少量非随机弱标签样例，没有像素真值；其2/6图片级结果与主数据集像素分割指标分开报告。

## 评价入口

准备好环境、数据和对应本地权重后，在项目根目录执行：

```powershell
python -m scripts.evaluate --split val --model-dir "outputs/run_20261024_181934_060182"
python -m scripts.evaluate --split test --model-dir "outputs/run_20261024_181934_060182"
```

默认使用验证清单。入口要求CUDA；数据和权重的获取限制见[环境与复现说明](环境与复现说明.md)。
