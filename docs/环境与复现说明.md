# 环境与复现说明

本项目已在下列Windows环境完成训练、CUDA整图评价和单图命令行预测。完整依赖快照见 [requirements-lock.txt](../requirements-lock.txt)；现有环境的 `python -m pip check` 输出为 `No broken requirements found.`。**全新环境重建尚未验收**，依赖一致性检查不能替代该验收。

## 安装步骤

以下以Conda和CUDA环境为例，是根据已运行环境整理的安装说明，尚未在全新环境完整执行。

```powershell
conda create -n crack-seg-repro python=3.11.16
conda activate crack-seg-repro
python -m pip install "torch==2.14.1+cu126" "torchvision==0.29.1+cu126" --index-url https://download.pytorch.org/whl/cu126
python -m pip install -r requirements-lock.txt
python -m pip check
```

后两条命令在项目根目录执行。锁文件不包含安装索引，因此先从[PyTorch cu126索引](https://download.pytorch.org/whl/cu126)安装对应CUDA包。相应版本在各系统和Python版本下的安装包可获取性尚未重新验证。

安装后可检查解释器、包版本与CUDA状态：

```powershell
python --version
python -c "import torch, torchvision; print(torch.__version__); print(torchvision.__version__); print(torch.cuda.is_available())"
python -m scripts.check_environment
```

训练、续训和整图评价入口显式使用CUDA。单图预测具有CPU回退分支，但该分支尚未单独验收。

## 准备数据与权重

从[数据说明](数据说明.md)中的作者页面获取数据，按下列布局放置原图和标注。三份编号清单随源码提供；数据和模型权重不包含在Git仓库中。

```text
data/
├─ train_ids.txt
├─ val_ids.txt
├─ test_ids.txt
└─ raw/metu_v1/
   ├─ rgb/
   └─ BW/
outputs/
└─ run_20261024_181934_060182/
   └─ crack_segmentation_model.pth
```

epoch20权重目前只有本地文件，尚无公开下载链接；没有该文件时，不能直接运行示例预测或复核既有成绩。首次训练可从ImageNet预训练编码器开始。续训还需要指定检查点中的优化器与历史文件。

单图预测只需照片和模型权重文件：

```powershell
python -m scripts.predict --image "data/raw/metu_v1/rgb/582.JPG" --model "outputs/run_20261024_181934_060182/crack_segmentation_model.pth"
```

输入高、宽均须至少512；当前程序显示结果，尚无通用导出和目录批量预测入口。评价、训练及续训命令见[代码结构与运行入口](代码结构与运行入口.md)。

## 复现范围

固定划分、推理规则和权重SHA-256见[评价方法](评价方法.md)，最终成绩及原始输出见[最终测试报告](../reports/evaluation/unet_resnet34_final_test.md)。当前材料支持追溯既有实验，不保证他人在全新环境直接重现。

训练按seed=1重建原图划分，应与已保存编号核对；恢复训练未保存全部随机状态，不承诺训练轨迹逐位一致。验证集用于选模，最终测试集只用于冻结版本后的评价。
